# Лабораторна робота №1. Домен і модель даних (ER)

## Мета роботи

Описати дані предметної області «Каталог відеоігор та бібліотека
користувача» за допомогою ER-моделі: визначити сутності, їхні
атрибути, ключі та зв’язки.

## Опис предметної області

Система містить каталог відеоігор. Для кожної гри зберігаються
назва, опис, дата виходу та жанри. Одна гра може належати до
кількох жанрів, а один жанр може об’єднувати багато ігор.

Користувач може додавати ігри з каталогу до особистої бібліотеки.
Для кожної доданої гри зберігаються дата додавання та статус
проходження: «Заплановано», «У процесі» або «Пройдено».

Одна гра може бути в бібліотеках різних користувачів.
Кожен користувач має власний статус проходження цієї гри.
У бібліотеці одного користувача гра може бути додана лише один раз.

## Межі моделі

У межах роботи розглядаються:

- користувачі;
- відеоігри;
- жанри;
- записи в особистій бібліотеці користувача.

Купівля ігор, платежі, відгуки, друзі та ігрові досягнення
не входять до меж цієї моделі.

Робота охоплює моделювання даних без реалізації застосунку
та фізичної схеми бази даних.
